# Audit perilaku opening chat

Cakupan: transisi preview streaming ke pesan tersimpan atau error pada panel video. Perbaikan backend tidak mengubah desain, copy, atau komponen frontend.

## Temuan

1. **HIGH, R-27: pesan recovery tetap menyatakan penyimpanan belum pasti setelah rekonsiliasi berhasil.** `apps/app/features/video/components/VideoWorkspace.tsx:177–204` menambahkan “Percakapan mungkin sudah tersimpan”, lalu tetap mempertahankan `openingError` ketika pembacaan ulang berhasil tetapi tidak menemukan pesan. `readWorkspace` hanya menghapus error opening jika ada pesan (`:118`). Copy tidak menjelaskan hasil pembacaan ulang yang sudah diketahui. Temuan ini belum diperbaiki karena mode audit membutuhkan persetujuan nomor temuan sebelum mengubah UI.

## Bukti perbaikan backend

- Provider nyata mengirim `response.completed` berstatus `completed` dengan `output: []`, disertai item assistant final berstatus `completed`.
- Opening “Nama produk apa yang dipromosikan?” berhasil mengalir dan tersimpan pada proyek yang dilaporkan; sebelum smoke ada nol pesan, sesudahnya ada satu pesan assistant.
- Adapter memakai item final berdasarkan `output_index` hanya saat output terminal sukses berupa array kosong. Preview delta dan event text completion tanpa item tidak menjadi hasil final.
- Komponen tetap memiliki status loading, alert error, tombol retry, dan reload (`VideoChat.tsx:35–42, 111–116, 152–169`). Audit kode tidak menggantikan verifikasi visual atau interaksi browser.

## Batasan

Browser terpisah diarahkan ke login. Koneksi relay ke tab pengguna timeout. Tampilan panel, kontras, layout responsif, dan interaksi keyboard belum diverifikasi secara visual. Tidak ada klaim lulus audit visual menyeluruh.
