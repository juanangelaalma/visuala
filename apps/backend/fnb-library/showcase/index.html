Composition notes

Frames preserve 9:16 geometry. At 1080px wide they are 1920px tall. Set body data-debug="true" for safe-area and center guides. Override --safe-* for the delivery platform.

Load the four shared CSS files in registry order. Layout fragments expose empty data-slot containers. Free placement uses .hf-place and percentage variables --x, --y, --w, --h, plus --z.

Examples load composition recipes and instantiate the same source fragments. They are static demonstrations, not video timelines.

Agent handoff

Read the main registry → select components and variants → select compatible motion IDs → load the named files → compose a scene → let Hyperframes supply timing and rendering.

Replace img[data-asset] sources and alt text. Set --product-count to 2–5 for stacks. Ingredient indices are stable animation selectors. Background images use --background-image:url(...).

Motion definitions are intent, not executable adapters. Resolve targets within each instance, choose a compatible target, and preserve the authored static pose. Transitions act on incoming/outgoing scenes, not individual components. No motion preview runs automatically.

Serve the project over HTTP: npx http-server . -p 4173, then open /fnb-library/showcase/. Fetching fragments from file:// is not supported by browsers.
